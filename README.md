# TOP5 CC Shorts Auto — V13 (한국어 안내)

**주제 검색 → Wikimedia Commons CC BY·CC0 영상 자동 발견 → 5개 파일 자동 다운로드 → 30초 TOP5 세로영상 초안 → 출처·권리 검토 자료 출력**

이 프로젝트는 **검수용 초안 자동 생성기**입니다. 자동 업로드하거나 원본 사용권을 자동으로 보증하지 않습니다. 유튜브 광고 수익화도 보장하지 않습니다.

## 휴대폰으로 실행하기 (최초 설정 1회)

1. GitHub에서 새 저장소를 만듭니다. 예: `top5-shorts-auto`. 실행용 GitHub Actions를 쓰려면 `.github/workflows/top5.yml`이 저장소의 **기본 브랜치**에 있어야 합니다.
2. 이 ZIP의 **압축을 풀어 내부 파일 및 폴더 구조 그대로** 저장소에 올립니다. ZIP 파일 하나만 업로드하면 워크플로는 작동하지 않습니다. 직접 올리기 어렵다면 저장소 URL을 ChatGPT에 알려 코드를 넣는 방법을 안내받으세요.
3. GitHub 모바일 앱 또는 웹에서 저장소 → **Actions** → `TOP5 CC Shorts - discover and draft` → **Run workflow**를 누릅니다.
4. `mode = discover`이면 검색 후보와 출처 목록만 생성합니다. `mode = draft`이면 권리 정보가 기록된 영상 5개 다운로드 및 30초 검수 초안까지 시도합니다.
5. 완료된 Actions 실행 화면의 **Artifacts**에서 `TOP5-shorts-review-...` ZIP을 내려받으면 `TOP5_DRAFT_REVIEW_ONLY_1080x1920.mp4` 등 결과물이 있습니다.

> `Run workflow`가 없으면 워크플로가 기본 브랜치에 배치됐는지, Actions 권한이 켜져 있는지 확인합니다.

## 설정

- `topic`: 영어 검색어 예: `funny cats`, `dog playing`, `kitten playing`
- `title`: 화면 상단 한국어 제목
- `mode=discover`: CC 메타데이터 후보 확인만. 무료/빠름.
- `mode=draft`: 후보 수집 → 5개 원본 파일 자동 다운로드 → 자동 편집. 원본 영상 길이가 너무 짧거나 API 요청이 제한되면 실패하며, 성공을 가장하지 않습니다.
- `sample/script.json`: 편집 중 표시되는 장면별 한국어 자막. 기본 문구는 임시 문구이므로 **실제 영상 확인 후 독창적 해설·스토리로 바꿔야** 수익화 품질을 갖춥니다.

## 영상 구성 (30초)

- 00–02초: 1위 영상 티저 + 제목
- 02–07초: 5위
- 07–12초: 4위
- 12–17초: 3위
- 17–22초: 2위
- 22–27초: 1위
- 27–30초: 다시보기와 댓글 유도

영상은 1080×1920, H.264/AAC, 24fps이며 원본 오디오를 **의도적으로 제거**합니다(저작권 문제가 있는 배경 음악 전파 방지). 검수 초안의 오디오 트랙은 무음입니다. 대사는 별도 TTS 음성 파일을 입력해 제작하거나 추후 기능으로 연결해야 합니다. 기본 랭킹 문구와 자막만 있는 초안은 유튜브 수익화용 완성본이 아닙니다.

## 권리와 제한

- Wikimedia Commons `LicenseUrl`에 **정확히 CC BY 2.0/2.5/3.0/4.0 또는 CC0 1.0이 표시되는 파일만** 수집합니다. BY-SA, NC, ND 등은 자동 후보에서 제외합니다.
- 이 필터는 **신고된 메타데이터**만 검사하며 원본 제작자·음악·출연자·브랜드 등 제3자 권리를 검증하지 못합니다. `RIGHTS_CHECKLIST.md` 확인 필수.
- 최소 길이 5.25초, 파일당 약 60MiB, 총 약 220MiB 이하로 제한합니다. API 데이터 오류·다운로드 오류·후보 부족이면 실패합니다.
- 초안의 순위는 **검색 목록 순서**입니다. 재미·완성도 순위가 아닙니다. 공개 전 꼭 직접 판단하세요.
- 작품별 출처·창작자·라이선스·변경 사항은 `YOUTUBE_CREDITS.txt`에서 확인하고, 라이선스 조건에 따라 실제 설명란에 표시하세요.
- CC BY라 하더라도 유튜브의 `재사용 콘텐츠` 규정으로 수익화가 거절될 수 있습니다. 독창적 해설·분석·유머·재편집을 추가하세요.
- GitHub Actions의 사용 가능 시간, 아티팩트 저장 기간 및 저장소 공개 범위는 본인 설정·요금제에 따라 다릅니다. 공개 저장소에서는 Actions 결과물과 원본 출처가 노출될 수 있습니다.
- 영상 화면은 기존 특정 채널의 직접 복제품이 아닌 TOP5 형식의 자체 디자인입니다.

## 로컬 개발 테스트

Python 3.10+ / FFmpeg + ffprobe / 한글 NanumSquare 폰트 필요.

```bash
python3 -m unittest discover -s tests -v
python3 src/top5.py --mode discover --topic 'cat playing' --output output
python3 src/top5.py --mode draft --topic 'cat playing' --output output
```

외부 네트워크가 막힌 환경에서도 5개 로컬 영상 파일의 테스트용 JSON 목록으로 렌더만 검증할 수 있습니다.

```bash
python3 src/top5.py --mode local-test --local-manifest local.json --size 360x640 --output test-output
```

> `local.json`에는 `title`, `source_page`, `author`, `license`, `license_url`, `review_flags`, `local_path`, `duration`을 가진 영상 5개 객체 배열이 필요합니다.

## V3: 움직임 분석·기본 효과음·음성 대본 (검수용)

- 검색 메타데이터에서 애니메이션·영화·합성 콘텐츠로 보이는 제목은 1차 제외합니다. 제목 검사이므로 실제 실사 여부는 사람이 확인해야 합니다.
- 후보 최대 9개를 확보해 각 영상의 시작 48초 범위에서 5초 구간의 움직임을 간단한 프레임 차분으로 계산합니다.
- 동작 점수, 영상 제목의 활동 관련 키워드, 가로 영상의 세로 크롭 손실 위험을 종합해 TOP5 예비 순위를 만듭니다. **웃김이나 완성도를 식별하는 AI는 아닙니다.**
- 원본 음악·효과음은 제거하며, 직접 합성한 짧은 전환 효과음만 추가합니다.
- `VOICEOVER_TIMELINE.json`에 타이밍별 한국어 음성 대본 제안이 저장됩니다. 음성 파일이 제공되지 않으면 TTS는 없습니다.
- `MOTION_RANKING_REPORT.json`, `SHOTLIST_FOR_REVIEW.json`, `QA_CONTACT_SHEET.jpg`에서 편집 및 크롭 품질을 확인하세요.
- 화면은 9:16 전체를 채우지만 가로 영상의 피사체가 잘릴 수 있습니다. 자동 움직임 분석은 인물·동물 인식을 대신하지 않습니다.
- 최초 실행 후 채널용 제작을 위해 실제 장면에 맞게 순위별 해설을 직접 수정해야 합니다.
- 사용권은 Commons 메타데이터 1차 확인만 수행합니다. 영상 속 음악, 인물, 제3자 저작물과 원작자의 실제 권리는 보장하지 않습니다. YouTube 수익화도 보장하지 않습니다.

### 현재 제공하는 오디오

- `전환음`: 직접 합성한 단순 사인파 사운드 (무음 대비 개선)
- `한국어 음성`: **미포함**. 상업적 사용권이 확인된 음성 파일을 CLI의 `--narration`에 지정하면 합성할 수 있습니다.
- 비공식 무료 TTS 서비스를 사용해 권리 검증 없이 수익화용 음성을 자동 생성하지 않습니다.


## V4: 후보 검수 우선 / 원본-세로 비교

**기본 실행 모드는 이제 `review`입니다.** 자동으로 30초 영상을 완성했다고 표시하지 않습니다.

- `review`: Commons에서 메타데이터상 CC BY/CC0 동영상 후보를 검색하고 최대 9개를 확보합니다.
- `REVIEW_ORIGINAL_GRID.jpg`: 각 원본의 화면 전체를 보여주는 3×3 비교 이미지입니다.
- `REVIEW_VERTICAL_GRID.jpg`: 같은 순간을 9:16으로 크롭한 3×3 비교 이미지입니다.
- `REVIEW_PREVIEWS/01.mp4` ~ `09.mp4`: 왼쪽 원본/오른쪽 세로 크롭을 동시에 보여주는 5초짜리 무음 동작 검수 영상입니다.
- `REVIEW_SHORTLIST.json`: 출처·라이선스 메타데이터·움직임 점수·크롭 위험·검수 필요 상태가 기록됩니다.
- `REVIEW_GUIDE.md`: 9개 후보에 대한 체크리스트입니다.

**주의:** 화면이 잘리지 않았는지 확인하려면 원본(왼쪽)과 9:16 크롭(오른쪽)을 함께 봐야 합니다. 3×3 원본 프리뷰는 비교용 검은색 여백을 사용하며, 최종 쇼츠에 흐림 배경을 넣는 것은 아닙니다. 화면 가득 채우는 최종 편집에서는 원본 가로 영상의 일부가 잘릴 수 있습니다. 가로 크롭 손실이 55%를 넘는 소스는 자동 경고합니다.

`draft`: 이전처럼 원본 5개를 선정하여 자동 MP4 검수본을 생성하지만 편집품질·수익화·원권리자의 적법성은 보장되지 않습니다. 최종 승인은 원본 영상의 전후 맥락, 초상권, 원래 오디오/음악 권리, 장면의 재미·서사·자막과 TTS의 독창성 등을 직접 확인한 뒤 진행해야 합니다.

한국어 음성은 외부 사용권이 명확한 TTS 오디오가 필요합니다. 자동으로 음성 제공업체에 연결하거나 유료 API를 호출하지 않습니다.

### V4: 원하는 5개만 선택해서 제작

`review`의 `REVIEW_SHORTLIST.json` 및 5초짜리 원본/세로 비교 미리보기를 검수한 후, 실제 사용하기로 결정된 5개만 `sample/selection.json`에 **5위부터 1위 순서**로 등록합니다.

예시(반드시 자신의 검수 결과로 교체):

```json
[
  {"title": "File:Example5.webm", "start_sec": 5, "display_name": "5위 별명", "focus_x": 0.5},
  {"title": "File:Example4.webm", "start_sec": 8},
  {"title": "File:Example3.webm", "start_sec": 2},
  {"title": "File:Example2.webm", "start_sec": 15},
  {"title": "File:Example1.webm", "start_sec": 1}
]
```

이후 Actions에서 `mode=selected-draft`로 실행합니다. 파일을 하나하나 다운로드하거나 재업로드할 필요 없이 지정한 원본의 적법한 라이선스 **표기를 재조회**하고, 원본을 다운로드해 30초짜리 검수용 MP4를 만듭니다.

- `start_sec`: 선택한 원본 영상에서 사용할 5초 구간 시작 (생략하면 움직임 분석)
- `focus_x`: 가로로 잘리는 영역의 중심 비율 (0=왼쪽, 0.5=중앙, 1=오른쪽)
- `display_name`: 순위표에 표시할 짧은 이름 (실제로 확인한 장면에 맞게 작성)
- `sample/script.json`의 `exclude_titles`: 장면 검수에서 부적합하다고 판정한 원본을 다음 검색에서 제외함

**주의:** `selected-draft`는 편집상 선정된 후보를 뜻할 뿐 원본 영상 사용권이나 수익화를 보증하는 `approved` 상태가 아닙니다. CC 메타데이터 외 제3자 권리/원작자 권리 검증과 독창적 해설은 여전히 필수입니다.


## V5: 검은색 고정 프레임 / 원본 비율 보존

**채택된 기본 디자인:** 1080×1920(9:16) 캔버스는 모든 컷에서 검은색으로 유지합니다.

- 상단: 한국어 TOP5 제목 고정
- 왼쪽 약 23%: 1~5위 번호 및 각각의 이름을 세로로 고정
- 가운데·오른쪽: 원본 영상을 비율 그대로 맞춰 배치 (가로·세로 모두 크롭 없음)
- 하단 검은 영역: 한국어 구간별 자막과 게시 전 검수 표기 고정
- 블러·스모그·배경 확대·강제 9:16 크롭 없음
- 16:9 가로 원본은 옆으로 긴 영상창이 나타납니다. 검은 여백이 넓어져 영상이 작아 보일 수 있으나 피사체 손실을 줄입니다.
- 9:16 세로 원본도 같은 순위·제목·자막 레이아웃을 사용합니다.
- V4의 움직임 기반 초안 검색·권리 확인·9개 후보 검수 기능은 유지합니다.
- 검수 JPG와 5초 비교 미리보기 역시 V5의 검정색 레이아웃을 사용합니다.

`src/top5.py`의 `stage_geometry()`가 모든 비율에서 공통인 영상창의 위치/크기를 계산합니다.
`SHOTLIST_FOR_REVIEW.json`의 `crop_mode`는 `black_fit_no_crop`으로 기록됩니다.
일반 영상의 크롭 손실 비교는 남아 있어도 V5 출력물에는 크롭이 적용되지 않습니다.

**게시 전 주의:** 검은색 프레임은 영상 저작권·유튜브 재사용 콘텐츠·원본 사용권의 해결책이 아닙니다.
동물 장면의 재미, 독창적인 해설, 실제 라이선스/제3자 권리, TTS 품질과 자막 싱크는 별도 검수가 필요합니다.

## V6: 확대된 영상 영역, 높이 65% 자막, 선택적 현장음

- 세로 1080×1920을 고정하고 왼쪽 순위표 영역을 약 20%로 축소하여 영상을 약 5~7% 더 크게 표시합니다.
- 가로 영상도 **원본 전체를 유지**하며 화면 자르기/블러 없이 검은 바탕에 맞춥니다.
- 한국어 자막 중앙 좌표는 **(540, 1248)**로, 전체 영상 세로 높이의 정확히 65%에 고정합니다.
- 채널 이름과 좋아요 버튼 등이 겹칠 수 있는 화면 맨 아래에 자막을 배치하지 않습니다. 실제 모바일 재생 화면 확인은 필수입니다.
- 한국어 음성(TTS)은 기본으로 넣지 않습니다. 독창적 코미디 해설은 편집할 실제 컷에 맞춰 자막으로 보강해야 합니다.
- 원본 오디오는 저작권·음악·출연자 음성 검토가 끝난 개별 파일만 `audio_approved: true`로 표시해 사용할 수 있습니다.
- 오디오 승인 표시가 없는 파일은 무음 원본에 **자체 제작 전환 효과음**만 적용합니다. 이는 안전을 위한 기본값이며 무음 소스에 대한 수익화 보증이 아닙니다.
- 원본 소리를 포함하면 48kHz 2채널로 정규화하고 효과음과 함께 혼합합니다. 게시 전 최종 듣기 검수는 필수입니다.
- 결과물 `AUDIO_RIGHTS_REVIEW.md`에 원본별 오디오 승인과 오디오 스트림 존재 여부가 기록됩니다.

### 원본 오디오 승인 예시

`sample/selection.json`에 5위부터 1위 순서로 실제 확인한 후보 5개를 등록한 뒤, **오디오 권리 검증을 마친 영상에만** 다음 필드를 지정합니다.

```json
{"title":"File:Example.webm","start_sec":12,"display_name":"고양이 반전","audio_approved":true}
```

원본 전체에 음악이 있는 경우 CC 영상 표시만으로 음악을 포함한 오디오까지 자동으로 쓸 수 있다고 볼 수 없습니다. `audio_approved=true`는 사용자의 검토를 기록하는 설정이지, 라이선스의 존재를 증명하지 않습니다.

**참고:** 자동 발굴 `draft` 모드의 원본 오디오는 검토 전이므로 비활성화됩니다. `selected-draft` 모드에서 승인된 원본만 현장음을 사용합니다. 현재 자동으로 '웃긴 장면'을 이해·판정하는 기능은 없습니다.

## V12 — 기존 CC 자동 제작 + 신규 상업 이용 영상 소스 후보 검수

기존 Wikimedia Commons의 CC BY/CC0 수집·검수·편집 기능은 그대로 유지됩니다. V12는 별도의 \`source-review\` 모드를 추가합니다.

### 왜 별도 모드인가

Pixabay/Pexels/Mixkit 동영상의 **사용 라이선스**와 실제 동영상의 **내용이 웃긴지**는 별개입니다. 더구나 Mixkit은 Free와 Restricted가 달라서 개별 영상 페이지 확인 없이 일괄 다운로드하면 안 됩니다. 현재 공급사 사용 조건도 대량 스크래핑을 허용하는 포괄적 동의가 아닙니다. 따라서 V12는 출처 검토 전의 원본 다운로드를 자동화하지 않습니다.

### 휴대폰에서 후보 7개 확인하기

1. GitHub 저장소 → Actions → TOP5 CC Shorts - discover and draft → Run workflow.
2. mode = \`source-review\` 선택.
3. 실행 후 Artifacts → TOP5-shorts-review-… ZIP 다운로드.
4. ZIP 안의 \`V12_MOBILE_REVIEW.html\`을 휴대폰 브라우저에서 열면 후보 원본 페이지/라이선스 링크를 볼 수 있습니다.
5. \`V12_SOURCE_REPORT.json\`, \`V12_SOURCES.csv\`, \`V12_RIGHTS_AND_EDITORIAL.md\`에 제작자 표기, 실제 액션 검수, 음악/초상/제3자 권리 검수 상태가 기록됩니다.

### 추가 후보 사이트별 정책

- **Pexels**: 공식 Pexels License는 일반적 상업 편집 사용이 가능하지만 단순 무변형 배포, 제3자 로고·초상·원본 음원 등을 별도로 검토해야 합니다. Pexels API는 현재 **신규 키 발급이 일시 중단**돼 있습니다. 이미 키가 있으면 GitHub Actions Repository secret의 이름을 정확히 \`PEXELS_API_KEY\`로 지정할 수 있으며, \`source-review\` 실행 시 최대 8건씩 두 검색어로 **후보 메타데이터만** 받아옵니다. 키가 없으면 API 요청을 시도하지 않고 이미 검증한 출처 페이지 7개를 보여줍니다. API 키나 요청 URL의 민감값을 로그/아티팩트에 출력하지 않습니다.
- **Pixabay**: 개별 페이지가 Pixabay Content License 대상인지 확인하고, 동영상 자체가 실사인지 AI 영상인지, 음악/권리가 포함됐는지 검수합니다. 무변형 재배포 금지.
- **Mixkit**: 개별 영상에 \`Mixkit Stock Video Free License\`가 표시되는 경우만 후보로 인정하며 \`Restricted License\`는 제외합니다. 특정 영상의 이용권과 원본 다운로드 권한을 구분합니다.
- **Wikimedia**: 기존의 CC BY·CC0 필터와 출처 표기 방식 유지, 제3자 권리 검토 필요.

### 필수 검수 및 다음 제작 기준
