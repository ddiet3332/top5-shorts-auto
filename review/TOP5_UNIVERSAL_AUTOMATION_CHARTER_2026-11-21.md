# TOP5 Shorts Auto — channel-wide automation contract (2026-11-21)

## Confirmed owner direction (overrides dog-only optimization)
This is **not a dog or cat channel**. Produce themed TOP5 videos across **animals, people, objects, and nature**, with varied emotions (funny, touching, surprising, suspenseful). Dogs are one test topic, never the default product or the definition of completion. Select a coherent theme for each episode, not an arbitrary mixture of unrelated clips.

## Delivery and fixed safety contract
1. Discover and recommend different topics, with diversity and recency awareness. Today's 24-topic planner is a **curated rotation**, not open-ended AI semantic trend research. Never claim otherwise.
2. Gather at least five technically valid, distinct **original** clips. Record exact provenance, creator, download/hash, and license conditions. Discovery metadata, movement magnitude, Pexels/Pixabay label, or a successful build do not prove funny action or monetization rights.
3. Actually observe the **selected five cuts** and first 1–3 seconds of hook. Write true, original Korean captions only from scene-matched visual evidence; no imaginary gag, names, emotions, outcomes, ranking, or automatic 100-point score inferred from metadata. Until reviewed, use review-only placeholders and report that explicitly.
4. Respect the owner-approved TOP5 layout and channel-neutral branding. Preserve the existing, working dog-specific design lock. Reuse approved creative principles in other categories rather than silently replacing the template. No TTS unless specifically requested. Audio requires listening and rights verification.
5. Technical output: approximately 30s, 1080×1920, 24fps H.264/AAC, 5 separate ranked scenes plus coherent hook/ending where available; full frame and audio decode.
6. Score **the actual rendered MP4**, not a single 5-second candidate, under the 7-part /100 rubric: hook 20; fun/emotion/reversal 25; ranking 15; cut flow 15; creative captions 10; sound 10; rights/monetization 5. Below 75 revise; 75–84 continue improving; **85+ is only a publication candidate**, never automatic permission.
7. Original authorship, license, likeness/music/trademark/third-party permissions, and YouTube reused-content monetization status are independent hard gates. If any remain unverified, **publication_approved=false** and never claim success for posting.
8. User manually uploads to YouTube. **No auto-publish**, no fabricated rights claims, no bypasses, no paid API without approval.
9. Store immutable GitHub Actions evidence, source hashes, failures, MP4/QA artifacts; do not repeatedly report a cached unchanged MP4 as a new successful creative iteration.
10. Compare actual outcomes across **four families** before claiming the general-purpose auto-video system works. The broad trial must report technical successes and source shortfalls separately, with actual topic-specific artifacts and explicit editorial/rights blockers.

## Operating priority
P0: run independent end-to-end cat / people / objects / nature trials on the same shared engine. Prove real source acquisition → original MP4 → decoder check for each; explain shortfalls precisely.
P1: unify broad-topic 5-cut visual review, caption writing, ranking, and source-window matching; no generic placeholder as final publication output.
P2: automate bounded re-edit using evidence and score, with rights hard gate. Retain existing dog V32 improvements as a specialist regression, not primary backlog.
P3: manual publishing package only after 85+ whole-video review AND individual rights and reused-content checks. No automatic uploads.

**Definition of done**: at least one independently verified distinct-topic pipeline in each core family, multiple different usable TOP5 episodes, 85+ editorial quality on published candidates, provenance/third-party/monetization safeguards demonstrated, and actual downloadable user-reviewed MP4s. A green CI badge, 5-second clip score, or dog-only batch is insufficient.
