# TOP5 V18 — 실제 검수 → 30초 초안 연결

이 문서는 유튜브 자동 게시 기능 설명이 아닙니다. **권리 검증 전에는 모든 결과를 검수용으로만 취급**합니다.

## 검수 없이 자동으로 만들지 않는 이유
- 파일명에 “funny”, “jump”가 있어도 실제 5초 동안 해당 행동이 일어나지 않을 수 있습니다.
- 영상이 움직인다는 사실은 재미나 반전을 증명하지 않습니다.
- CC BY / CC0 메타데이터와 원저작자·음원·출연자 권리 또는 유튜브 수익화 심사는 별개입니다.

## 현재 동작 순서
1. GitHub Actions V17 검색 실행 후 latest.json에 실행 번호, 후보, 실제 미리보기 시각, 이용조건 메타데이터가 저장됩니다.
2. latest_editorial_template.json과 templates/<실행ID>.json이 자동 생성되며 모든 후보는 기본 **미검수·미선정·게시 불허**입니다.
3. ChatGPT는 GitHub 연결을 통해 현재 실행의 MP4 아티팩트를 직접 가져와 행동, 반전, 오류를 실제 재생 검수합니다. 사용자는 ZIP을 반복 업로드할 필요가 없습니다. 다만 대화 밖에서 무조건 백그라운드 검수를 수행하는 기능은 아닙니다.
4. 실제 유효한 5초 컷 다섯 개가 확보되면, 그중 5위→1위를 명확한 증거·한국어 도입/반전 자막과 함께 review/v18_decisions.json에 기록합니다. 선정된 다섯 컷은 모두 각각 원본 고유 제목, 원본 시작 시각, 실제 미리보기 근거, 화면 행동 설명을 가져야 합니다.
5. GitHub Actions에서 mode=v18-selected-draft를 실행하면 V18이 해당 실행의 소스 인덱스와 선택을 교차검증합니다. 5개가 부족하거나 미검수·권리 승인 사칭·출처 불일치·실제 미리보기 없는 시작 초이면 렌더링을 차단합니다.
6. 통과하는 경우 기존 top5.py를 호출하여 CC BY/CC0 메타데이터를 다시 확인하고 원본을 다시 다운로드해 30초 H.264/AAC, 1080×1920/24fps 검수 초안과 출처·오디오 권리 검토서를 출력합니다. 소스 오디오는 사용하지 않습니다.
7. 완성 영상의 **원래 7항목 100점 평가**를 진행합니다. 제작 목표 75점, 게시 후보 85점. 개별 원본 권리/제3자 권리·유튜브 수익화 리스크가 검증되지 않으면 점수와 관계없이 게시 보류입니다.

## 의도적으로 차단된 부분
- V17이 자동으로 TOP5를 뽑거나 자막을 지어낼 수 없습니다.
- 4초짜리 원본은 현재 V18의 5초 순위칸에 자동 늘리거나 반복하지 않습니다. 별도 시간 변형 QA가 필요합니다.
- 현재 100점 평가는 실제 편집본 검수 전까지 모두 미평가입니다.
- 동작·시각 정보는 검수의 근거이지 원본 권리 승인 정보가 아닙니다.
- 어떤 GitHub Actions 모드도 유튜브 업로드를 자동 실행하지 않습니다.
