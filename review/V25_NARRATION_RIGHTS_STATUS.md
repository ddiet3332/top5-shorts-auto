# V25 제작 기준 정정 — 내레이션 없는 상황 자막 쇼츠 (2026-11-15)

> **이 문서는 기존 V25 내레이션 지시서를 대체한다.** 앞서 준비한 SAMI TTS 7구간, 음성 ZIP 처리 및 음성 합성 가이드는 사용자 최종 결정과 다르므로 제작 지시에서 제외한다. 기존 파일이나 시험용 음성이 있더라도 사용하지 않는다.

## 사용자가 확정한 방향

- **내레이션, TTS, 대사 없음.**
- 실제 고양이의 행동과 화면 전환에 맞는 **재미있는 한국어 상황 자막**을 영상 안에 삽입.
- 자막이 영상과 어긋나거나 실제로 없는 장면을 꾸며내지 않도록 실제 MP4 프레임을 기준으로 검수.
- 첫 2초 화면 자체의 훅 유지, 5위→1위 순서 유지, 마지막 3초 다섯 실제 장면 엔드카드 유지.
- 자막 중심은 약 화면 높이 65%를 기본으로 하되 동물 얼굴·핵심 동작을 가리지 않도록 필요 시 해당 구간만 안전 영역 내 위치 조정.
- 이미 V23에 있는 검은 여백 내 행동 분석 문구는 중복 글자가 과도해지지 않도록 조정.
- 음악/원본 소리/미확인 음원은 추가하지 않는다. 기존 자체 제작된 전환·효과음 및 원본 음소거 유지. TTS 자동 믹스/오디오 더킹 단계는 **V25에서 사용하지 않는다**.
- CapCut이나 SAMI에 사용자가 음성 파일을 생성하도록 요청하지 않는다.
- 자막의 재미·창작성은 실제 영상에 반영한 뒤에만 100점 기준으로 재평가. 기존 V23 **81/100**은 자동 상승시키지 않는다.

## 기존 V25 작업의 처리

- 기존 7구간 음성 대본/CSV/음성 muxer/내부 시험 신호는 **폐기 대상의 미채택 시안**이다. 테스트 통과가 사용자 요청에 맞는 제작 완료를 의미하지 않는다.
- 새로운 기계 판독용 상황 자막 기준은 `sample/v25-situation-captions.json`에 보관한다.
- 기존 V23 실사용 30초 MP4 및 GitHub Actions 제작 과정은 변경하거나 손상시키지 않고 보존한다.
- 앞으로 V25 제작 결과물은 영상·자막 타이밍·장면 일치·효과음·30초 디코딩 QA와 100점 평가를 거친 뒤 검수본만 제공한다.
